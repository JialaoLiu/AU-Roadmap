// FIXED

1. Searchbar 页面需要权限
   搜索结果直接跳转到登录页
   原因：navigateToResult 函数将结果跳转到 /student/alumni、/student/industry
         这些路由设置了 requiresAuth: true，未登录用户触发导航守卫被重定向到登录页
   解决：改为跳转公开路由 /research/connect、/research/connect#partner，
         无需登录即可访问

2. 标题颜色不清晰
   原因：深色背景上使用了默认文字颜色，对比度不足，影响可读性
   解决：调整标题 color 使用高对比度颜色或白色，确保符合 WCAG 可读性标准

3. .env 数据库配置问题
   原因：.env 文件中 DB_HOST / DB_USER / DB_PASSWORD / DB_NAME 配置项
         与本地 MySQL 实际参数不匹配，或 .env 文件未被正确加载
   解决：核对 .env 文件各项参数与本地数据库一致，
         确认 server.js 顶部已调用 require('dotenv').config()

4. 数据库导入报错
   ERROR 1050 Table 'users' already exists
   ERROR 1062 Duplicate entry
   原因：重复执行 schema.sql 导致表已存在冲突；
         重复执行 seed.sql 导致主键/唯一键重复插入
   解决：schema.sql 改用 CREATE TABLE IF NOT EXISTS；
         seed.sql 执行前先 TRUNCATE 相关表，或使用 INSERT IGNORE

5. 登录失败（Invalid email or password 401）
   原因：seed.sql 中密码字段为明文字符串，
         但 auth controller 使用 bcrypt.compare() 做验证，明文无法匹配
   解决：将 seed.sql 中所有密码改为对应的 bcrypt hash 值
         （如密码 11111111 对应 $2b$10$gRRlcc...）

6. 控制台警告：The next() callback in navigation guards is deprecated
   原因：router/index.js 的 beforeEach 使用了 Vue Router 3 风格的 next() 回调，
         Vue Router 4 中该方式已弃用
   解决：将 next({ name: 'Login' }) 等写法改为 return { name: 'Login' }，
         使用 return 值代替 next() 回调


// 0318 → 0414 FIXED

7. Roadmap 页面 popup menu 显示课程 ID 而非课程名
   原因：RoadmapTimeline.vue 中 Prerequisites 和 Required For 列表直接渲染
         prereq.course_id / depId 数字，未做 ID → 课程名映射
   解决：在 RoadmapTimeline.vue 中新增 courseMap computed，
         将 roadmap prop 中所有课程展平为 { id: course } 映射表，
         渲染时改为 courseMap[id].code + courseMap[id].name，
         找不到时降级显示 Course {id}

8. Search bar 搜索跳转课程后显示空白
   原因：navigateToResult 对 courses 类型执行 router.push('/explore/programs/${item.id}')，
         item.id 是课程 ID 而非 program_id，导致跳转到不存在的 program 页面显示空白；
         同时 searchController.js 的 courses 查询未返回 program_id 字段
   解决：searchController.js 的 courses 查询 LEFT JOIN program_courses，
         返回 MIN(pc.program_id) AS program_id；
         SearchBar.vue navigateToResult 改为使用 item.program_id 跳转，
         无 program_id 时降级跳转到 /explore

// 0401 FIXED

11. 执行数据库迁移脚本时报错，ALTER TABLE 无法运行
    原因：MySQL 不支持 ALTER TABLE ADD COLUMN IF NOT EXISTS 语法（PostgreSQL 支持）
    解决：改为先查询 information_schema.columns 判断字段是否已存在，
          再决定是否执行 ALTER TABLE

12. Community 调用私信会话列表 API 时 MySQL 返回错误
    原因：MySQL 默认开启 only_full_group_by 模式，
          SELECT 中 m.content、m.created_at 未出现在 GROUP BY 或聚合函数中，执行被拒绝
    解决：重构 SQL，用子查询先找出每组对话的 MAX(id)，
          再 JOIN 回 messages 表取完整字段

13. 修改 auth.js 新增 optionalAuth 后，后台多个路由全部报错
    原因：原导出方式 module.exports = authenticate（直接导出函数），
          改为 module.exports = { authenticate, optionalAuth }（对象导出）后，
          原有 const authenticate = require('../middleware/auth') 引用失效
    影响：routes/auth.js、routes/discussions.js、routes/admin.js 共 3 个文件
    解决：将三处 import 改为解构形式
          const { authenticate } = require('../middleware/auth')

14. Alumni 用户 ID 与 seed.sql 预期不一致
    原因：seed.sql 假设 alumni 用户 ID 为 4-12，
          但线上数据库因已有数据存在 ID 空缺，实际插入后变为 10-18
    解决：线上 DB 手动使用正确 ID（10-18）插入 alumni_profiles；
          seed.sql 保留 4-12（适用于全新数据库初始化时）

15. Program 图片无法显示（HomePage program-card-img + ProgramPreviewPage hero banner）
    原因：ProgramPreviewPage.vue 和 HomePage.vue 使用 program.image 字段，
          但数据库字段名为 banner_url，且所有 program 的 banner_url 均为 NULL
    解决：数据库为 5 个 program 写入正确图片路径（/program/hero-banner-*.jpg）；
          前端两处改为 program.banner_url / p.banner_url；
          seed.sql programs INSERT 补充 banner_url 字段

16. 添加课程默认归属 CS，数据库中无对应记录
    原因：Admin 新增课程流程只创建 courses 记录，未同步写入 program_courses；
          前端表单也没有显式的 program roadmap 绑定字段，造成“像是默认属于某个 program，但数据库无映射”的误解
    解决：ManageCourses 新增可选 Program Assignment 字段；
          createCourse 支持在创建课程时可选同步写入 program_courses，
          由管理员明确指定 year_level / semester / course_group / sort_order

23. 控制台警告：The next() callback in navigation guards is deprecated
    原因：router/index.js 的 beforeEach 使用了旧式 next() 回调，Vue Router 4 已弃用
    解决：所有 next({...}) 改为 return {...}，next() 改为隐式 return，移除 next 参数

24. ProgramPreviewPage crash（TypeError: Cannot read properties of undefined 'employment_rate'）
    原因：programs 2-5 无 career_outcomes 数据，latestOutcome 为 undefined，
          v-if 直接访问 latestOutcome.employment_rate 导致报错
    解决：v-if 加空值守卫 latestOutcome && latestOutcome.employment_rate

25. Dashboard / Resources 无 program 时显示空白
    原因：authStore.user.program_id 为 null 时页面无任何提示，用户不知道原因
    解决：两页面均添加"No program assigned"提示，引导用户联系管理员

26. seed.sql 重复插入 MIT career_outcomes 导致 Duplicate entry 报错
    原因：seed.sql 同时存在两个 career_outcomes INSERT，均包含 (program_id=3, year=2023)
    解决：删除旧的 MIT 专用 INSERT 块（lines 256-260），保留统一的全 program INSERT

27. 头像上传成功后图片短暂显示破损图标（刷新后正常）
    原因：uploadAvatarHandler 将文件保存到 frontend/public/avatar/，
          前端 handleAvatarUpload 上传成功后将 avatarPreview 从 blob URL 切换为服务器路径
          /avatar/user_x_xxx.jpg，但 Vite dev server 尚未服务该新文件，导致图片加载失败
    解决：移除 avatarPreview.value = res.data.data.avatar_url 这行，
          保持上传前 onFileChange 创建的 blob URL 作为预览，
          仅更新 authStore.user.avatar_url 为服务器路径供后续使用

28. Student 端页面错误显示顶部白色主导航栏
    原因：AppHeader.vue 未区分 public 页面与 /student/* 门户页面，
          main-nav-bar 在 student portal 中仍被统一渲染，造成导航冗余
    解决：在 AppHeader.vue 中基于当前路由判断，
          /student/* 下隐藏白色 main-nav-bar，仅保留 portal 所需顶部信息栏

29. Sidebar 折叠后导航 icon 视觉不居中
    原因：侧边栏 collapsed 状态下 sidebar-link 仍沿用展开态 padding 和对齐方式，
          导致 icon 整体偏右
    解决：为 collapsed 状态单独设置 sidebar-nav / sidebar-link / icon 的居中规则，
          确保折叠后导航图标水平居中

30. Timetable 在阿德莱德时区下“今天”显示错误
    原因：TimetablePage.vue 使用 toISOString().slice(0, 10) 生成 todayStr 和 dateStr，
          该写法按 UTC 截日期，导致 Australia/Adelaide 本地日期被偏移
    解决：改为统一按 Australia/Adelaide 时区生成日期 key，
          并据此计算 today 高亮和周标题显示

31. My Profile 错误提供姓名/邮箱可编辑表单
    原因：Profile 页面将学生姓名和学校邮箱作为可编辑字段展示，
          与学生主数据通常由学校系统维护的业务规则不一致，造成误导
    解决：改为只读账户信息展示，
          保留头像上传，移除姓名/邮箱编辑表单及 Program ID 展示

32. MIT Roadmap 错误显示会计/农业/航空等非 IT 课程
    原因：seed.sql 中 MIT 的 program_courses 映射仍写死为 course_id 13-26，
          但这些 ID 实际已被 ACCT / AGRI / EDUC / AERO / BUSI 等课程占用；
          真正的 MIT 课程在当前 seed 顺序下是 57-70
    解决：修正 seed.sql 中 MIT 的 program_courses 映射为正确 course_id，
          并同步更新本地数据库中 program_id = 3 的课程映射记录

33. Homepage Featured Programs 图片不显示
    原因：HomePage.vue 依赖 programs.banner_url 渲染 program-card-img，
          但当前数据库 programs.banner_url 全部为 NULL；
          同时首页直接取按名称排序后的前 4 个 program，无法保证命中已有本地 banner 的专业
    解决：首页 Featured Programs 改为固定展示 4 个 demo program，
          并为其提供本地 banner fallback；ProgramPreviewPage 同步增加 banner fallback

34. Auth 注册 / 登录校验规则未真正生效
    原因：routes/auth.js 虽挂载 express-validator 中间件，
          但 authController.js 的 register / login 未调用 validationResult(req) 读取校验结果
    解决：在 register / login 开头显式检查 validationResult(req)，
          校验失败时直接返回 400 VALIDATION_ERROR，阻止无效请求继续进入 bcrypt 和数据库逻辑

35. Discussion 发帖 / 回复校验规则未真正生效
    原因：routes/discussions.js 已挂载 threadValidation / replyValidation，
          但 discussionController.js 的 createThread / createReply 未读取 validationResult(req)
    解决：在 createThread / createReply 开头显式检查 validationResult(req)，
          空标题 / 空内容请求直接返回 400 VALIDATION_ERROR

36. Community 私信发送时缺少 receiver_id 校验
    原因：communityController.js 的 sendMessage 仅校验 content，
          未校验 receiver_id 是否存在且为合法用户 ID，错误请求会直接落到 messages 表外键约束
    解决：sendMessage 中新增 receiver_id 必填与数值合法性校验，
          不合法时返回 400 VALIDATION_ERROR，避免 DB 层 500

37. Community 连接请求可因类型不一致绕过“不能连接自己”校验
    原因：sendConnectionRequest 中 requesterId 来自 JWT 为 number，
          receiver_id 来自 req.body 可能为 string，严格相等比较可能失效
    解决：对 receiver_id 做 Number() 归一化与合法性校验，
          再用数值比较判断是否为 self-connect

38. Community 连接请求响应 action 无效时会被静默当成 reject
    原因：respondToConnection 使用 action === 'accept' ? 'accepted' : 'rejected'，
          任何拼写错误、大小写错误或缺失字段都会被当成拒绝
    解决：仅允许 action 为 accept / reject，
          其余情况返回 400 VALIDATION_ERROR，避免误拒绝待处理请求

39. Auth store 在任意 fetchUser 错误下都会强制登出
    原因：frontend/src/stores/auth.js 的 fetchUser catch 中无条件调用 logout()，
          临时网络错误或 5xx 也会清空本地 token
    解决：仅在响应状态码为 401 时执行 logout()，
          其余错误保留 token，避免瞬时后端故障导致用户被动退出

40. Student sidebar 的 Dashboard 在所有子页面都被高亮
    原因：Level1Layout.vue 使用 .router-link-active 作为完整高亮样式，
          而 /student 是所有 /student/* 路由的前缀，导致 Dashboard 始终处于 active 状态
    解决：将完整高亮样式改为 .router-link-exact-active，
          普通 .router-link-active 仅保留轻量文字提示

41. Admin Dashboard 的 Resources 卡片跳转到错误页面
    原因：AdminDashboard.vue 中 Resources stat card 的 route 配置为 /admin/careers，
          点击后会进入职业数据管理页而非资源相关页
    解决：将 Resources 卡片跳转暂时调整为 /admin/programs，
          作为更接近资源管理上下文的临时入口

42. My Profile 头像上传按钮依赖非响应式 FileList
    原因：Upload 按钮通过 fileInput?.files?.[0] 判断显示，
          DOM FileList 非 Vue 响应式数据，文件清空或取消选择时按钮状态可能不同步
    解决：新增 selectedFile 响应式 ref 统一管理选中的文件，
          Upload 按钮改为基于 selectedFile 显示

43. 分页响应在 limit=0 时返回无效 totalPages
    原因：backend/utils/response.js 中 paginated 直接计算 Math.ceil(total / limit)，
          当 limit=0 时会得到 Infinity
    解决：对 limit 做最小值保护，
          使用 safeLimit = Math.max(1, parseInt(limit) || 1) 计算 totalPages

44. 头像上传清理旧文件时空 catch 吞掉错误
    原因：authController.js 的 uploadAvatarHandler 在清理旧头像文件时使用空 catch，
          文件系统或 DB 查询异常会被完全吞掉，后续排查困难
    解决：将空 catch 改为输出 warning 日志，
          至少保留 cleanupErr.message 供后续定位

45. Community 发帖上传图片后未刷新页面时显示裂图
    原因：CommunityHubPage.vue 发帖成功后先将本地 blob 预览图复用到新帖子，
          但随后 clearThreadImage() 立即对该 blob URL 执行 URL.revokeObjectURL()，
          导致帖子中的本地图片地址被提前销毁
    解决：发帖成功后若新帖子仍使用本地预览图，
          清空表单时不立即 revoke 该 blob URL，仅重置 input 和状态；
          刷新页面后再自然回到服务器 /posts/... 图片路径
