# AU Roadmap 数据库设计参考

## 概览

共 **14 张表**，采用模块化关系数据库设计，支持 Program Roadmap 平台的所有核心功能。

---

## 表结构总览

| # | 表名 | 用途 | 对应功能 |
|---|------|------|----------|
| 1 | `users` | 用户账号、角色 (student/prospective/admin) | 登录系统、权限控制 |
| 2 | `programs` | 专业信息（名称、学院、ATAR、学费等） | Level 2 专业浏览、Level 1 学生归属 |
| 3 | `courses` | 课程信息（代码、学分、学期、描述） | Roadmap 基础单元 |
| 4 | `program_courses` | 专业-课程映射（年级、学期、核心/选修） | **核心：Roadmap 可视化** |
| 5 | `prerequisites` | 课程前置/共修关系（自引用） | Roadmap 前置课程连线 |
| 6 | `industry_partners` | 行业合作伙伴公司信息 | Level 1 行业连接板块 |
| 7 | `program_industry` | 专业-企业映射 | 展示每个专业的合作企业 |
| 8 | `alumni` | 校友资料、故事 | Level 1 校友网络 |
| 9 | `career_outcomes` | 毕业生就业统计数据（年度） | Level 2 职业前景图表 |
| 10 | `career_paths` | 职业路径（职位、薪资、需求度） | Level 2 职业方向 |
| 11 | `resources` | 学生支持资源链接 | Level 1 学生资源页 |
| 12 | `content_blocks` | CMS 内容块（页面各区块） | 首页、营销页面内容管理 |
| 13 | `key_dates` | 关键日期（学期、考试、毕业） | Dashboard 日历、Level 2 时间线 |
| 14 | `campus_highlights` | 校园亮点（设施、社团、城市） | Level 2 校园生活页 |

---

## 核心关系图

```
users ──FK──> programs
program_courses ──FK──> programs + courses   (胶水表：哪个专业在第几年第几学期上哪门课)
prerequisites ──FK──> courses + courses       (自引用：课程A是课程B的前置)
program_industry ──FK──> programs + industry_partners
alumni ──FK──> programs
career_outcomes ──FK──> programs
career_paths ──FK──> programs
resources ──FK──> programs (可选)
key_dates ──FK──> programs (可选)
```

## 各表字段详解

### 1. users
```sql
id, email (UNIQUE), password_hash, first_name, last_name,
role ENUM('student', 'prospective', 'admin'),
avatar_url, student_id, program_id (FK -> programs),
created_at, updated_at
```
- `role` 区分三种用户：当前学生、潜在学生、管理员
- `program_id` 关联学生所属专业

### 2. programs
```sql
id, code (UNIQUE), name, level ENUM('undergraduate','postgraduate','research'),
duration_years, faculty, description, overview_html,
entry_requirements, atar_requirement,
international_requirements, fees_domestic, fees_international,
application_deadline, is_active, thumbnail_url, banner_url,
seo_title, seo_description, created_at, updated_at
```
- `level` 支持本科/研究生/研究型
- SEO 字段用于 Level 2 营销页面

### 3. courses
```sql
id, code (UNIQUE), name, units, level ENUM('1000','2000','3000','4000','postgrad'),
semester_offered SET('S1','S2','Summer'),
description, learning_outcomes, assessment_summary,
is_elective, is_active, created_at, updated_at
```
- 一张表统一管理，用 `is_elective` 区分核心/选修
- `semester_offered` 用 SET 支持多学期开课

### 4. program_courses（胶水表）
```sql
id, program_id (FK), course_id (FK),
year_level, semester, is_core,
course_group, sort_order
```
- **Roadmap 的核心逻辑**：决定每门课在路线图上的位置
- `is_core` 在映射层再次标记（同一门课在不同专业可能是核心或选修）
- `course_group` 用于分组显示（如 "Core", "Specialisation"）

### 5. prerequisites（自引用关系）
```sql
id, course_id (FK -> courses), prerequisite_course_id (FK -> courses),
is_corequisite BOOLEAN
```
- 课程间的前置依赖关系
- `is_corequisite = true` 表示可以同学期修读

### 6. industry_partners
```sql
id, name, industry_sector, description, logo_url, website_url,
partnership_type ENUM('internship','research','sponsorship','employment','guest_lecture'),
contact_email, is_active, created_at, updated_at
```

### 7. program_industry（多对多映射）
```sql
id, program_id (FK), industry_partner_id (FK), opportunity_description
```

### 8. alumni
```sql
id, first_name, last_name, graduation_year, program_id (FK),
current_role, current_company, location, bio, success_story,
photo_url, linkedin_url, is_featured, is_active, created_at, updated_at
```
- `is_featured` 控制首页/重点展示

### 9. career_outcomes（统计数据）
```sql
id, program_id (FK), year,
employment_rate, median_salary, salary_range_low, salary_range_high,
further_study_rate, satisfaction_rate, source
```
- 按年度存储，用于 Chart.js 数据可视化

### 10. career_paths（职业方向）
```sql
id, program_id (FK), job_title, description,
average_salary, demand_level ENUM('high','medium','low'),
industry_sector, sort_order
```

### 11. resources
```sql
id, title, description, url, category ENUM('academic','career','wellbeing','financial','technology','library'),
icon, program_id (FK, 可选), is_active, sort_order, created_at
```
- `icon` 存储 Material Symbols 图标名（如 `edit_note`, `work`）

### 12. content_blocks（CMS）
```sql
id, page_key, section_key, title, subtitle, body_html,
image_url, cta_text, cta_url, sort_order, is_active, updated_at
```
- 灵活的 CMS 系统，按 `page_key + section_key` 定位内容

### 13. key_dates
```sql
id, title, description, event_date,
category ENUM('application','orientation','semester','examination','graduation'),
program_id (FK, 可选), is_active
```

### 14. campus_highlights
```sql
id, title, description, image_url,
category ENUM('facilities','events','clubs','accommodation','city'),
is_featured, sort_order, created_at
```

## 设计原则

1. **数据解耦**: 课程 (courses) 与专业 (programs) 通过 `program_courses` 映射，同一门课可被多个专业引用
2. **自引用关系**: `prerequisites` 表实现课程间前置依赖，支持 corequisite
3. **灵活 CMS**: `content_blocks` 表支持任意页面内容管理，无需改代码
4. **统计与个人分离**: `career_outcomes`（统计数据）和 `alumni`（个人故事）分开存储
5. **多对多映射**: `program_industry` 实现专业与企业的灵活关联
